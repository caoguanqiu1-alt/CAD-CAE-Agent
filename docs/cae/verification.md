## 销轴接触

三实体、两组无穿透接触，大销轴固定，小销轴 +X 1000 N，两个轴向限位及一个 Z 向导向。
材料均为本机 6061-T6 (SS) 库参数、线弹性各向同性。

| 网格 mm | 最大 URES mm | 峰值 von Mises MPa |
| ---: | ---: | ---: |
| 4 | 0.011187851 | 10.9183 |
| 3 | 0.011214720 | 11.4927 |
| 2 | 0.011234013 | 12.4418 |

位移变化 0.240% / 0.172%；应力变化 5.00% / 7.63%，**未收敛**。
2 mm 固定端 Fx 为 -1000.000244 N。单次计划入口另跑 5/4/3 mm 接触算例，
末次 URES 为 0.011214703 mm，保存关闭重开后结果保持一致。

只加接触但未加限位的模型曾返回 0.373 / 52.032 / 31.793 mm 位移。
该异常说明求解器成功不足以判定工况有效；补充限位的依据必须来自真实安装方式，不能只为得到小位移而添加约束。
